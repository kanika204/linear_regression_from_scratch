# linear_regression_from_scratch
Implementation of Linear Regression from scratch using the mathematical slope formula and gradient descent, applied on CSV data to validate model behavior, and compared with standard Linear Regression.

Overview:
This project focuses on building Linear Regression from first principles, without relying on machine learning libraries for model training.
The goal is to understand how Linear Regression works mathematically and how optimization through Gradient Descent converges to the same solution.

The implementation is validated using:
- Analytical (mathematical) slope formula
- Gradient Descent optimization
- Standard Linear Regression (library-based) for comparison

 Objectives:
- Understand the mathematics behind Linear Regression
- Implement Linear Regression from scratch in Python
- Apply the model on real CSV data
- Compare analytical and iterative optimization approaches
- Validate results with standard Linear Regression

Methods Implemented:
1️⃣ Mathematical Slope Formula
- Uses closed-form equations to compute: Slope (m) and Intercept (c)
- Represents the exact analytical solution

2️⃣ Gradient Descent
- Iterative optimization technique
- Minimizes Mean Squared Error (MSE)
- Demonstrates convergence behavior

3️⃣ Standard Linear Regression
- Library-based implementation
- Used to validate results obtained from scratch methods
